# Provenance

Catalog Q74 points to Open Problem 3 in Shyan Akmal’s 2024 thesis, printed page 92. The discovery packet supplied the unit-conflict search and a Python check. The earlier manuscript supplied the exact count formulation, explicit exponent, and conditional Vertex Cover lower bound. The current paper reconstructs the proof from those sources and makes the threshold input convention and carry-cost argument explicit.

The earlier manuscript reported a separate set of test counts. This repository reports only its runnable replay.
