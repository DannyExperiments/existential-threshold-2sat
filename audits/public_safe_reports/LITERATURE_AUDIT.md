# Literature check for Catalog Q74

Search date 26 November 2026. Confidence is high in the distinctions among the named theorems and moderate in the priority conclusion. The record supports presenting an affirmative answer to the linear-in-formula question under an exact count-threshold convention. It does not establish historical priority.

## Direct sources

- Akmal, *Parameterized Relaxations for Circuits and Graphs* (MIT dissertation, 2024), Theorem 4.16 and Algorithm 4, printed pp. 83–85, gives an $n^{O(\log(1/p))}|\varphi|$ algorithm for the same existential $\ge p$ problem. It enumerates bounded-size sets of residual $y$ units and choices of a mixed-clause witness per unit. Claim 4.17 handles the purely probabilistic clause cover. On printed p. 92, Open Problem 3 asks whether the problem can be “solved in $f(1/p)|\varphi|$ time for some computable function $f$.” This is a linear formula factor, stronger than ordinary FPT with an unspecified polynomial factor. [Thesis at MIT](https://hdl.handle.net/1721.1/156299) · [Open Problem 3](https://www.shyanakmal.com/publications/ShyanAkmal_PhD-Thesis.pdf#page=92)
- Akmal and Williams, *MAJORITY-3SAT (and Related Problems) in Polynomial Time*, full version v2 (2021), Theorem 3.1, printed p. 7, gives an “$m\cdot\mathrm{poly}(1/\alpha)$-time algorithm” for the unquantified rational threshold question. Its proof uses a maximal disjoint family and enumerates assignments to the covered variables. Theorem 6.1, printed p. 31, assigns existential variables first and gives $n^{O(\log(1/\rho))}$ time. Its proof divides clauses into the same three groups and enumerates small residual-unit sets. The bounded search tree used here replaces that enumeration. Theorem 6.3 concerns two nested probability comparisons, for which identifying one passing witness does not supply the number of good outer assignments. [Theorem 3.1](https://arxiv.org/pdf/2107.02748v2#page=8) · [Theorem 6.1](https://arxiv.org/pdf/2107.02748v2#page=32) · [Theorem 6.3](https://arxiv.org/pdf/2107.02748v2#page=34)
- Tantau, *On the Satisfaction Probabilities of $k$-CNF Formulas*, v4 (2024), Corollary 1.4 and Theorem 1.11 give linear-time and kernel results for a single probability threshold on an input formula, via spectral gaps. Corollary 3.20 studies nested majority quantifiers and the requisite witness subset argument. These are different quantified decisions. Theorem 1.11 uses a constant depending on $k,p$, so linear time for fixed $p$ alone gives no stated polynomial bound in $1/p$. [Corollary 1.4](https://arxiv.org/pdf/2201.08895v4#page=3) · [Theorem 1.11](https://arxiv.org/pdf/2201.08895v4#page=8) · [Tantau v4](https://arxiv.org/abs/2201.08895v4)
- Aspvall, Plass and Tarjan (1979), pp. 121–123, supplies the linear implication-graph solver for 2-SAT. The two-source certificate for added units uses graph closure and contrapositive edges. It is a standard width-two consistency mechanism. [Original publication](https://doi.org/10.1016/0020-0190(79)90002-4)

## Grouped feasibility and a weaker implication from prior methods

- Razgon and O’Sullivan, *Almost 2-SAT Is Fixed-Parameter Tractable* (2008), parameterize by the number of individual clause deletions. Foucaud, Hocquard, Lajou, Mitsou and Pierron give Group Deletion Almost 2-SAT in IPEC 2019 Proposition 11 and Algorithmica 2022 Proposition 22 (p. 1203). Their groups consist of clauses having a shared variable. A selector $z_v$ for each $y$-label gives a group of clauses $u\vee z_v$ with a shared selector, so these are relevant feasibility mechanisms. The decision in Q74 also requires an identity-dependent count after choosing a group set, so feasibility alone is insufficient. Example: choosing $y_1$ or $y_2$ in the teaching instance both admits an $x$-model, while the two surviving counts are $4$ and $3$ at threshold $4$. [Razgon–O’Sullivan](https://arxiv.org/abs/0801.1300) · [IPEC Proposition 11](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.IPEC.2019.15) · [Algorithmica Proposition 22](https://perso.limos.fr/ffoucaud/Publications/Papers/J38_GraphMod_EC-HOM_Algorithmica_2022.pdf)
- Creignou, Ktari, Meier, Müller, Olive and Vollmer, *Parameterised Enumeration for Modification Problems* (2019), Theorem 6, explicitly enumerates all inclusion-minimal bounded-weight models of a fixed-language constraint formula in FPT total time. There is a weaker Q74 consequence by combining old tools. For each label $v$, call $U_v$ the $x$-units from clauses with that label. If $A$ is satisfiable, precompute all unary and binary label obstructions using satisfiability of $A\wedge U_v$ and $A\wedge U_v\wedge U_w$. A complementary implication pair always has at most two unit sources, so the positive selector CNF with these obstructions describes feasibility exactly. Apply Theorem 6 (or standard bounded vertex-cover enumeration) to its size-$d$ inclusion-minimal models, then perform the old count test at each. A feasible $S$ whose count passes contains an inclusion-minimal feasible subset whose count also passes. This gives ordinary FPT with an explicit construction using up to quadratically many pair tests. It does not give the linear formula factor. The present algorithm finds an applicable obstruction at each node without building the projected CNF. [Theorem 6](https://www.mdpi.com/1999-4893/12/9/189)

## Encoding and search limits

The input probability determines the count cutoff $N=\lceil2^{n_y}p\rceil$. The $O((1/p)^c|\varphi|)$ formula-processing bound assumes that cutoff is supplied. With $p=a/b$ as independently encoded positive binary integers, the candidate charges the exact conversion separately at $O((n_y+L)L)$ bit operations for $L=\max(\mathrm{bitlen}(a),\mathrm{bitlen}(b))$. For a fixed rational, this cost is linear in $n_y+1$. A fixed real threshold requires the corresponding exact cutoff convention. Input length can be arbitrarily large at a fixed numerical threshold.
